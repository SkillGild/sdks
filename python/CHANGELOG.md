# Changelog

## 0.1.0 (2026-10-06)

First public release.

- Catalog: list, search and fetch skills, including cover media, gallery and page copy;
  categories, tags, collections and featured skills.
- Hosted runs with idempotency keys.
- Hybrid tool sessions: start or resume, call tools, end.
- Account: current account, revoke the current API key, device login.
- Errors carry the HTTP status, API error code and Retry-After delay.
