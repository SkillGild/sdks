# Security policy

Please report vulnerabilities privately to **security@skillgild.dev** or through
[GitHub private vulnerability reporting](https://github.com/SkillGild/sdks/security/advisories/new).
Do not open a public issue. We aim to acknowledge reports within three business days.

These SDKs are thin REST clients. Authentication, entitlements, quotas and skill
execution are enforced by the SkillGild API, so most issues there belong to the same
address. Never paste API keys into issues, logs or bug reports; revoke a leaked key
from [your SkillGild account](https://skillgild.dev/account).
